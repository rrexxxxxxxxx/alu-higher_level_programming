The ``1-my_list`` module
========================

Using ``MyList``
----------------

    >>> MyList = __import__('1-my_list').MyList

A new list is empty:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

It sorts in ascending order:

    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]

The original list keeps its order:

    >>> print(my_list)
    [1, 4, 2, 3, 5]

Negative numbers and duplicates:

    >>> neg = MyList([3, -1, 0, -1, 2])
    >>> neg.print_sorted()
    [-1, -1, 0, 2, 3]

An already sorted list stays the same:

    >>> MyList([1, 2, 3]).print_sorted()
    [1, 2, 3]

It is still a list:

    >>> issubclass(MyList, list)
    True
    >>> isinstance(my_list, list)
    True
